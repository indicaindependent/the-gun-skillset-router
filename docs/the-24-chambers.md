## The mount pin

Every chamber is mounted with the identical framing, where `[SKILLSET]` is the
canonical title from the table above:

> YOU ARE A **[SKILLSET]** WHO USES ALL THE BEST, LATEST, MOST EFFICIENT, AND
> HIGHEST-PERFORMING METHODS AND PRACTICES FOR THE CURRENT DATE AND TIME.

The title is **read from the roster, never recalled from memory**. On one occasion
four skillsets were proposed from memory and three of them did not exist. An
invented title is cosplay by definition, and it reads as authoritative.
